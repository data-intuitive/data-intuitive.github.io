Our Solutions to Key Strategic Challenges

Future Proofing

Viash enables researchers to concentrate on the core functionality of their script, while Viash handles the future compatibility.
Viash enables easy rebuilding of modules with the latest versions and technologies, ensuring long-term compatibility.
Viash ensures seamless integration of new tools into existing workflows, enhancing flexibility and adaptation to evolving technologies.

Automate and Optimise

Viash automatically generates standardised, executable modules from your scripts.
Minimize errors by automated boilerplate code generation and expand operational possibilities.
Scientists can dedicate more time to research, while Viash handles the operational IT tasks.

Implement Modularity

Viash turns your scripts into self-contained executable modules. Each tool can easily be run as a stand-alone module or combined with other modules to build workflows.
Viash modules are easy to update and maintain, and remove the need to rebuild workflows with evolving technologies.

Enable Collaboration

Viash boosts collaboration across teams by creating standardised tools.
A Private Viash Hub* ensures secure, organization-wide collaboration.
The Public Viash Hub* fosters collaboration between academia and industry.

Manage Capabilities

Viash ensures the longevity of in-house knowledge by promoting reusability and standardization of tools while safeguarding expertise.
The high level of standardization provides the management with a clear overview for planning and resource management.

Achieve Industry-Readiness

Viash transforms academic scripts into industry-ready tools and workflows.

Our Solutions to Key Operational Challenges

Operations

Automate the creation of runtime containers from dependency specifications, seamlessly integrating them into standardised computational modules. This ensures data reproducability and enables efficient validation.
Generate the (boilerplate) code to turn a code block into a Nextflow module, allowing scalable execution as a stand-alone module or as part of a computational workflow.
Viash-generated modules are compatible with all Nextflow-supported platforms and ensure cross-platform functionality. Modules run on HPC systems, Amazon AWS and Google Cloud out of the box.
Generate executables from source scripts in the programming language of your choice. The executable includes all dependencies required to run your script, enabling immediate execution from without further configuration or installation.
Module and pipeline debugging facilities are built into every module that is generated.

Development

Your source script is packaged into an executable that manages all dependencies to run your script, ensuring compatibility and functionality.
The creation of data workflows is streamlined using either Viash Modules or other Viash-enabled workflows as building blocks. Each module can be executed as a stand-alone entity.
Unit testing for modules and workflows ensures their correct functioning in the larger data workflow.
Viash Hub automates continuous integration and deployment, including code merging, automated testing, version control, and deployment to Viash Hub environments, ensuring minimal manual effort during development.
Viash Hub tracks the versions of individual modules within a pipeline as well as the the overall pipeline version. This creates a comprehensive overview of experiments, updates, and compatibility.

Usability and Accessibility

Viash Hub adheres to FAIR principles by ensuring that ready-to-use Viash Modules are findable, accessible, interoperable, and reusable through advanced search, open access, DOI, support for multiple script languages, and comprehensive documentation.
Viash Hub offers an intuitive interface with one-click execution for data workflows, enabling users to perform complex analyses effortlessly.
Viash Hub provides intuitive navigation, responsive performance, robust functionality, comprehensive support, and strong security measures, ensuring a satisfying user experience.
Viash Hub features a beginner-friendly learning curve with step-by-step guidance, extensive documentation for rapid learning and quick project initiation.
The Public Viash Hub supports community contributions and user development by facilitating the creation of publicly available self-developed modules, enhancing collaborative biotech research.

Risk-Mitigation

Viash and Viash Hub are developed with vendor neutrality in mind: our vision is to allow building for different open-source platforms. The resulting executable does not require Viash anymore and can be run using the respective workflow platform.
Viash Hub includes peer reviews, comments, and testing for data analysis components. This allows users to provide feedback and ratings, simplifying the selection process based on community insights and scores.
Each Viash module contains the operational measures required for ISO 2700. Viash Hub employs robust security measures for containers, including access controls for both public and private platforms. Data Intuitive conducts regular security audits to protect sensitive data and intellectual property, striving for ISO 27001 compliance.
Achieving FDA 21 CFR Part 11 compliance in data workflow development is challenging, as it demands secure, traceable, and tamper-proof processes, along with proper audit trails and electronic signatures. While Viash natively generates some of these compliance features, Data Intuitive offers a comprehensive service to help organisations address the remaining challenges, ensuring workflows meet the stringent regulatory standards.
Validating data workflow code is essential to guarantee accuracy, reproducibility, and regulatory compliance. Without proper validation, workflows can yield unreliable results, risking both operational integrity and compliance. Data Intuitive provides expert validation services, ensuring that your workflows are thoroughly tested, reliable, and meet industry standards for consistency and performance.
